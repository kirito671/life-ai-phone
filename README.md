# 手机版：生活AI化 PWA

这是一个可以长期放在手机上的网页版本：

- 数据保存在手机浏览器本地，不需要连接电脑。
- 可以离线打开。
- 可以“添加到主屏幕”，像 App 一样使用。
- 支持导出/导入备份，换手机时可以迁移数据。

## 推荐用法：部署到免费静态托管

PWA 的离线缓存和“添加到主屏幕”需要 HTTPS 环境。推荐用下面任意一种方式部署 `phone` 文件夹：

### 方式一：GitHub Pages

1. 新建一个 GitHub 仓库。
2. 把 `phone` 文件夹里的所有文件上传到仓库根目录：
   - `index.html`
   - `style.css`
   - `app.js`
   - `manifest.webmanifest`
   - `sw.js`
   - `icon-192.png`
   - `icon-512.png`
3. 在仓库 Settings → Pages 里，把 Source 设为 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`。
4. 打开生成的网址，例如 `https://你的用户名.github.io/仓库名/`。
5. 在手机浏览器里打开这个网址，然后选择“添加到主屏幕”。

### 方式二：Netlify Drop / Cloudflare Pages / Vercel

把 `phone` 文件夹拖到这些平台的静态托管入口，得到一个 HTTPS 网址即可。  
之后在手机上打开网址，添加到主屏幕。

### 方式三：直接使用单文件版

如果不想部署，可以把 `life-ai-phone.html` 复制到手机里，用浏览器打开。  
这种方式也能记录数据，但部分手机浏览器对本地文件的存储支持不稳定，长期使用仍建议用上面的 HTTPS 部署方式。

## 手机上怎么用

1. 打开网址后，先进入“设置”，修改你的目标。
2. 在“记录”里填写吃饭、训练、睡眠、工作。
3. 在“日报”里点击“生成”，复制提示词到 ChatGPT、Claude、Kimi、豆包等 AI。
4. 在“设置”里定期点击“导出备份”，保存 JSON 文件。

## 数据说明

- 数据默认只保存在这台手机的浏览器里。
- 清除浏览器数据、卸载浏览器或更换手机，可能导致数据丢失。
- 建议每周导出一次备份；换手机时，在新手机打开同一网页并导入备份即可。
- 不设置账号、不上传服务器，隐私性更好。

## 开发说明

- 修改 `index.html`、`style.css`、`app.js` 后，如果已经部署过，需要把 `sw.js` 里的 `CACHE` 版本号加一，例如 `life-ai-phone-v2`，让手机更新缓存。
- `life-ai-phone.html` 是单文件离线版，修改源码后需要重新生成。
## 添加到手机主屏幕

### iPhone / iPad（Safari）

1. 用 Safari 打开部署好的 HTTPS 网址。
2. 点底部的“分享”按钮。
3. 选择“添加到主屏幕”。
4. 以后从主屏幕打开，就会像 App 一样全屏运行。

### Android（Chrome / Edge）

1. 用 Chrome 或 Edge 打开部署好的 HTTPS 网址。
2. 点右上角菜单。
3. 选择“安装应用”或“添加到主屏幕”。
4. 以后从主屏幕打开即可。

如果页面里出现“安装到手机”按钮，也可以直接点击它。
## 同一 Wi-Fi 局域网访问（临时方案）

如果暂时不想部署到 HTTPS 网站，可以让电脑和手机连接同一个 Wi-Fi：

1. 双击 `8-手机局域网访问.cmd`。
2. 窗口里会显示一个类似 `http://192.168.1.5:8765/phone/` 的地址。
3. 在手机浏览器里打开这个地址。

如果手机打不开：

- 确保手机和电脑连接的是同一个 Wi-Fi。
- 在 Windows 防火墙中允许 PowerShell 访问“专用网络”。
- 或者用管理员身份运行窗口里提示的 `netsh` 防火墙命令。

注意：局域网 HTTP 不是 HTTPS 安全环境，可能无法“添加到主屏幕”或离线缓存。  
长期使用仍然建议用 GitHub Pages、Netlify Drop、Cloudflare Pages 等 HTTPS 静态托管。
